# 武大附中 · 里世界 — 精绘版 1.5

基于 **异闻增强版 1.4** 增量修改。本次重绘突脸角色，重构第一人称 HUD，新增界面字号 / 准星设置与无声静态角色档案。保留原地图、碰撞、课表、难度、23 种异象、八步训练、恐怖 BGM，以及全部七条可收集结局。没有新增结局条件，也没有提高惊吓频率、闪光强度或音量。

**本文是完整玩法说明，后半部包含全部结局条件、结局文案和死亡分支剧透。** 以下以本包实际代码为准，不把旧注释中的设想、提示文案或尚未使用的死亡动画当成已经实现的玩法。

## 1. 运行与文件

直接使用浏览器打开 `dist/里世界_精绘版.html`。该文件已内嵌全部 HTML、CSS 和 JavaScript，无需联网下载图片、字体或音乐，不需要账号与后端。手机应在可以执行 JavaScript 的浏览器中打开，而不是停留在文件管理器的预览页面。

也可以将项目作为静态网站运行。在项目根目录执行：

```sh
python -m http.server 8000
```

电脑浏览器访问本机 8000 端口；手机联调时，访问同一局域网内该电脑的 IP 和端口。`index.html` 是分文件开发入口，`dist/` 是单文件交付入口；两者的游戏代码相同。本包没有自动发布到公网。

## 2. 精绘改版与保留的异闻功能

### 1.5 角色立绘

突脸不再使用简单椭圆五官。本版提供“窥视者”半身矢量立绘：独立的头颅、耳朵、面部明暗、眉弓、上下眼睑、虹膜、鼻翼、嘴唇、皮肤微纹理，以及旧校服的领口、领带、纽扣、衣料纹理和缝线。保留苍白、冷色的非写实怪谈风格，不使用外部照片。

“静默”和“惊吓”是两组独立表情，均以 1200 × 1600 透明画布缓存；惊吓发生时做表情过渡与叠加，不逐帧重建整张立绘。两组原始像素缓存合计约 14.65 MiB，浏览器合成与导出另有额外开销，不能据此推断全部显存用量。缓存可复用，但没有宣称在所有手机上达到固定帧率。

在主菜单或暂停菜单进入“恐怖与画面”，滚动到“界面与角色”，点击“角色档案 · 无声静态预览”。预览默认显示静默表情，点击“惊吓表情”才切换；不播放音效、不添加闪光、不启用恐怖模式，也不改变背包、结局或录音进度。预览暂停游戏时间，可关闭或返回设置。原有无脸群体、远处人影、俯视人物和大部分旧死亡演出不是这次重绘的对象。

### 1.5 第一人称 UI

第一人称使用独立的分区仪表：地点与天赋、时间与作息、中心方向刻度、精神 / 体力、照明与手机电量，不再在同一条大面板里堆叠。桌面底部工具栏居中；手机保留独立移动、疾跑、互动及底部六个工具入口。

中央采用角标焦框，可改成仅中心点或隐藏。情境提示会依据真实状态显示“站起来 / 坐下”、上楼、拾取等操作；既可按原键，也可点提示卡。拾取使用 F、其他常规互动使用 E，不会因为改了 UI 就改变按键优先级。方向刻度使用原角色角度：北为 0°，东为 90°。

“界面与角色”提供 90%–120% 字号与“精简辅助提示”。精简开启时第一人称收起原有成组黄色交互三角标，改由情境提示显示当前可做的操作；地上的物品和物品判定仍在，取消精简可以恢复这些三角提示。字号只改变界面文字，不缩小触摸按钮。照明状态与手机电量分别标注：本版没有新造一个手电电池系统。

界面偏好独立保存于 `wdfz_presentation_v15`，不会覆盖原存档。第一人称右上角“视角设置”也可进入同一设置面板。背包、地图、暂停和角色预览会正确收起中心操作框；恐怖事件中仍保留紧急停止入口。

以下为 1.4 已有功能，在本版继续保留。

### 第一人称与画面

按 `V` 或点击“视角”切换。第一人称采用紧凑状态栏、中央准星、方位 / 照明 / 电量提示，将互动、字幕和手机手指操作区分开。小地图默认隐藏，可以在“恐怖与画面”中开启；`M` 完整地图始终可用。电脑可点击画布请求锁定鼠标；浏览器不提供锁定时仍能用鼠标横移及左右方向键转向。

修正射线垂直距离的计算，避免重复校正导致的墙面失真；修正半透明射线列重叠造成的竖条纹。家具不再被射线当作顶到天花板的墙，但原有家具碰撞仍在。新增世界坐标地砖材质、墙面接缝、远近明暗、轻薄雾气及低密度尘粒。保留原俯视地图绘制，未添加或移动楼房、房间、楼梯与出口。

可分别调整亮度、鼠标 / 触屏转向灵敏度、镜头起伏、地面细节、尘粒和第一人称小地图；旧设置中的屏幕震动与画质继续有效。亮度只作用于场景画布，不改变判定或恢复 SAN。灵敏度调节不改变左右方向键的固定转向速度。

### 八步新手训练

尚未完成 1.4 八步训练时，进入新游戏会显示训练环节，旧版“已看教程”标记不会跳过这次新增训练。流程是：说明 → 起身 → 移动与疾跑提示 → 切换视角并实际转向 → 模拟课桌互动 → 查看并关闭背包 → 查看并关闭地图 → 生存规则说明。

练习在原有教学楼四楼进行，不添加独立地图。训练冻结课表、异象、增益倒计时和原剧情延迟任务；使用练习背包，不消耗真实道具，也不修改翻找记录。结束或跳过后恢复进入训练前的位置、时间、SAN、背包、搜索进度和活动状态，不会因看教程错过 11:45 的彩蛋窗口。

每步都有“跳过此步”，整段有“跳过训练”。主菜单“新手训练”可安排下一次新游戏重练；暂停菜单可直接回放当前局的训练。完成或整段跳过后写入独立完成标记，避免每次开局重复弹出。

### 可选恐怖模式

主菜单或暂停菜单打开“恐怖与画面”，先阅读提示，再选择“我已了解，开启恐怖模式”。**模式默认关闭，刷新页面后不会自动恢复开启状态，读档也不会代替玩家同意。** 它不是“梦魇”难度：原有伤害、异象权重、碰撞和四条路线不随此开关变化。

| 控件 | 实际行为 |
| --- | --- |
| 开启恐怖模式 | 开放本次会话的新增惊吓导演和三条可选异闻路线 |
| 纯氛围 | 开启模式，但关闭新增闪光、突脸及冲击音；保留 BGM 和异闻结局 |
| 闪光 | 单次亮度脉冲，默认不勾选；不会做连续高频频闪 |
| 突脸 / 黑影 | 控制贴近视野的精绘角色与余光人影 |
| 冲击音 | 控制合成敲击、噪声及低频突发音；另有独立音量 |
| 氛围 BGM | 与模式开关分开，普通探索时也可以播放或关闭 |
| 强度 | 调节新增闪光和冲击音强度，不修改怪物伤害 |
| “关闭恐怖 ×” | 游玩时可直接停止新增演出；打开其他面板时隐藏，避免遮挡关闭键 |

新增事件包括余光黑影、门外敲击、灯光骤变与短促突脸。启用后有至少 20 秒有效游玩时间缓冲；事件之间至少 24 秒冷却，常规随机间隔约 34–59 秒。新场景和回到页面后会延迟触发。暂停、地图、背包、清单、对话、训练和新增确认面板中不播放新增惊吓；某些要求站定 / 及时移动的原异象期间也不插入新惊吓。关闭或暂停会清除当前新增演出，不在恢复后补播。

新增惊吓播放期间，`Esc` 可以直接关闭恐怖模式。未播放时，`Esc` 保持关闭面板 / 暂停等原行为；锁定鼠标时浏览器也可能先处理 `Esc`，画面上的关闭按钮仍可使用。

**刺激提示：本作本来就含怪谈、死亡演出与原有闪回。关闭“新增闪光”或“纯氛围”并不删除原版内容。** 新增亮度脉冲不是快速频闪，声音也经过总音量和动态压缩，但不代表对所有玩家、耳机或音量设置都安全。开始前调低设备音量；不适时立即关闭效果或退出。没有强制全屏、锁定设备音量、绕过静音、调用摄像头或麦克风的功能。

### 恐怖氛围 BGM

本版新增 BGM 由 Web Audio 实时合成：低音持续音、轻微失谐、稀疏小调旋律与空间声像。它是本版写入的原创短动机，不需要外链 MP3，也不是将现有商业歌曲作为背景音乐。

首次真实点击 / 按键后才初始化音频。音乐音量、冲击音音量和原总音量相互独立；总静音对全部音频生效。暂停、地图和教程会淡出新增 BGM，返回游玩后淡入；死亡、结局和返回菜单会停止并释放新增音频节点。原有钢琴、雨、脚步、钟声等音效仍保留；原钢琴交互中的旋律与本次新增 BGM 是两个不同系统。

## 4. 开局、资源、难度与课表

你从教学楼四楼高二（二）班的座位醒来，初始时间 **11:40**，处于坐着状态。先按 E / “站起”才能移动。初始背包是学生证、手机、粉笔、平面图，另外四格空着。每局随机一种天赋。

SAN 为精神值，归零立即死亡。体力决定疾跑；上限 100，疾跑基础消耗 17 / 秒，停止后经短暂冷却以 11 / 秒恢复，低体力时不能继续疾跑。基础步行速度 21 世界单位 / 秒，满体力疾跑上限 36.4；实际疾跑速度会随体力下降。游戏没有新增跳跃、战斗、枪械或追踪任务箭头。

上课时间需要坐到教学楼标记为 `P` 的座位上，而不是只进入某间教室。当前原规则在教学楼 1–5F 都有 P 格，并不强制只有四楼有效。坐好可降低违规；在教室但没坐好，或去其他地方，会增加违规。自由时段违规缓慢下降。第一天违规达到 100 会回落到 52、扣 16 SAN 并短暂不适；第二天违规达到 100 会触发死亡。该违规保护与“预知梦”的异象保护是两个独立判定。

| 难度 | 规则 |
| --- | --- |
| 预知梦 `easy` | 异象间隔倍率 1.75，异象 SAN 消耗倍率 0.70；第一天候选异象缩小，经过 `anKill()` 的部分致命异象改为扣 26 SAN 并结束；可以发现异象解析纸条 |
| 梦魇 `hard` | 异象间隔倍率 0.70，异象 SAN 消耗倍率 1.30；第一天不缩小异象池，也没有上述 `anKill()` 首日保护 |

**“第一天保护”不是无敌。** SAN 耗尽、车库怪物、主动陷阱、天台第四次对视等直接死亡仍可发生；扣 SAN 本身也可能把精神降到零。新增恐怖模式可和任一难度搭配，不会偷偷切换难度。

## 10. 存档、偏好与结局记录

暂停菜单提供手动保存和读取，继续沿用 `wdfz_save_v1` 键名，新版写入 v2 存档结构，并兼容原 v1。新增 `expansion: {version:1, echoes:[...]}` 只记录本局三段录音的收集状态；加载时使用录音 ID 白名单，旧存档缺少此字段时从空记录开始。

恐怖开启状态不进入存档，也不写成下次自动开启偏好。显示 / 音频参数存于 `wdfz_expansion_v14`，八步训练完成标记存于 `wdfz_tutorial_v14`。结局档案独立于当前局，新游戏不会抹掉已经收集的结局；开始新局会清空未保存的本局进度与录音。

存档在浏览器本地，不上传。继续读到旧存档的前提是新版能访问**同一浏览器、同一站点来源**的存储。更换浏览器、站点、端口、隐私窗口或本地文件打开方式不自动迁移数据。推荐先保留旧文件，再在原站点原入口替换新版。存储被禁用、配额不足或 JSON 损坏时会显示错误；校验通过前不会用坏数据覆盖当前局。

训练、异闻确认和新增结局演出期间不保存临时模拟状态。原有异象进行中的阶段不是完整的逐帧录像式存档：读取后原异象等待状态会重新建立，缺失于旧版本的数据也只能用兼容默认值恢复。不要将存档理解为精确恢复每个正在播放的声音或每一个事件帧。
